1. Di cosa si occupa l’app

KineFit aiuta gli utenti a registrare allenamenti in palestra (esercizi, serie, carico, RPE), consultare storico e analitiche, gestire una streak di abitudine opzionale e collegare opzionalmente un account Garmin.

2. Dati trattati

Categoria Esempi Finalità
Account email, token di autenticazione Accesso tramite Supabase Auth
Attività fitness sessioni, serie, peso corporeo, note, preferenze streak Prodotto core, sync cloud e coda offline
Diagnostica eventi di crash / errore (Sentry) Stabilità; PII ridotta in app (sendDefaultPii: false + redazione)
Integrazioni token OAuth Garmin (se l’utente collega) Sincronizzazione dati wearable via edge function

3. Permessi Android

In linea con l’audit release (vedi docs/STORE_SUBMISSION.md §5), l’app dichiara / riceve in merge solo:

  • INTERNET — comunicazioni con Supabase, Sentry, OAuth Garmin
  • POST_NOTIFICATIONS — notifiche timer di recupero (Notifee)
  • VIBRATE — feedback aptico / timer
  • ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE — stato rete (NetInfo) per offline / online

Non vengono richiesti microfono, archiviazione esterna, overlay di sistema, allarmi esatti né sblocco biometrico per l’accesso ai dati locali SecureStore.
